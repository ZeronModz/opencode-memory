# Memory Index

## Structure
```
.opencode-memory/
├── INDEX.md              ← This file — full index
├── profile.md            ← User identity & preferences
├── rules.md              ← Memory management rules
├── sessions/             ← Daily conversation logs
│   └── YYYY-MM-DD.md
├── projects/             ← Project details & change logs
│   └── PROJECT_NAME.md
├── problems/             ← Problems & solutions (for prevention)
│   └── YYYY-MM-DD-topic.md
└── learned/              ← New knowledge, tricks, limitations
    └── YYYY-MM-DD-topic.md
```

## How to Use
1. **Startup**: Read INDEX.md → profile.md → today's session → all projects
2. **Reply**: Always Banglish
3. **Save**: Everything gets logged with timestamp
