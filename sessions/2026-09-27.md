- **textStart = 0x527680** (`.text` section starts `0x527630`, real funcs start
  0x50 later). `real_addr = textStart + functab_entryoff`.
  functab = `[nfunc+1]` pairs of `<II {entryoff, funcoff}>` at `PT+0x5503e0`.
  `_func` = `{entryoff u32, nameoff i32, ...}`, name = funcnametab[nameoff].

### 2. Corrected previous (wrong) conclusions
- Global `0x1d60070/0x1d60078` is **`crypto/rand.Reader`** (set by
  `crypto/rand.init.0`) — NOT a password. It is used in Encrypt/EO via
  `io.ReadAtLeast(rand.Reader, nonce, 12)` to fill the 12-byte nonce.
- Argon2 password is a **compile-time 32-byte constant copied by the code**,
  not a runtime global.
