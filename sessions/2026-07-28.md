### How APP_PASS works now:
1. Bot owner sets password via `/zeron-pass PASS` in Telegram
2. Same password set as `APP_PASS` env var in Vercel project
3. Frontend calls `/api/proxy?method=accounts` (no password in frontend)
4. Serverless function adds `Authorization: Bearer ${APP_PASS}` and forwards to backend
