## McpService.kt — Foreground Service Created

### File Created
- **McpService.kt** → `app/src/main/java/com/zeron/mcp/service/McpService.kt`

### What it does
- Foreground service that runs the Node.js MCP server (port 8787)
- Uses ProcessBuilder to spawn Node.js process
- Manages wake lock, notification channel, start/stop/restart lifecycle
- Reads stdout in real-time, logs to UI callback
- START_STICKY for auto-restart on kill
- Notification with "Stop" action button
- Node.js binary: `/data/data/com.termux/files/usr/bin/node`
- Build dir: `/data/data/com.termux/files/home/.zeron-mcp-build/dist/index.js`
