# Session 2026-08-24 — Patch 22: Menu Toggle Buttons (Dynamic)

## What Changed:
- Toggle buttons (Torch, WiFi, BT, GPS, Notif, Keylog) now stay in SAME menu
- Click toggle → action executes → SAME menu edits with updated button text
- Button text changes: "Torch ON" ↔ "Torch OFF", "WiFi ON" ↔ "WiFi OFF", etc.
- Button color changes: green (success) when OFF → red (danger) when ON

## Flow:
```
Menu: [💡 Torch ON] [📶 WiFi ON] [🔵 BT ON] [📍 GPS ON]
tap "💡 Torch ON" → torch turns ON
  → SAME menu edits → [💡 Torch OFF] [📶 WiFi ON] [🔵 BT ON] [📍 GPS ON]
tap "💡 Torch OFF" → torch turns OFF
  → SAME menu edits → [💡 Torch ON] [📶 WiFi ON] [🔵 BT ON] [📍 GPS ON]
```

## Helper Methods Added:
- `getMenuText()` — returns menu header text
- `MenuBtns(torchOn, wifiOn, btOn, gpsOn, notifOn, klogOn)` — builds full menu with dynamic button text
