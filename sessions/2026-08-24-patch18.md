# Session 2026-08-24 — Patch 18: ONE Message Dynamic Edit

## Core Change: Everything is ONE text message
- Removed photo-based welcome/menu flow
- Now using `sendTextWithButtonsGetId()` — sends text with inline keyboard, returns message_id
- `editTextWithButtons()` — edits same message with new text and buttons
- ALL states (welcome, menu, commands, status) edit the SAME message

## Flow:
```
/start → sendTextWithButtonsGetId (welcome text + buttons)
  ↓ tap "Menu"
  → editTextWithButtons (control panel) SAME message
  ↓ tap "Commands"  
  → editTextWithButtons (loading) + sendRichMessage (separate, too long)
  ↓ tap "Back"
  → editTextWithButtons (welcome) SAME message
  ↓ tap "Status"
  → editTextWithButtons (status info) SAME message
```

## New Methods:
- `sendTextWithButtonsGetId(chat, text, rows)` — sends text message with inline keyboard, returns msgId
- `editTextWithButtons(chat, msgId, text, rows)` — edits text message with new text and buttons
