### libandroidx.graphics.path.so — COMPLETE DECOMPILE (فرانسیس not needed, full logic decode)

**What it is:** Official **AndroidX Graphics Path** native library (`androidx.graphics.path` package) — open-source Android library. NOT malicious, standard Google lib.

**Exported:** only `JNI_OnLoad` (+ version node LIBANDROIDX.GRAPHICS.PATH)

**JNI_OnLoad (0x16c8) flow (decoded):**
1. `vm->GetEnv(env, JNI_VERSION_1_6)` at 0x16f4
2. `FindClass("android/graphics/Path")` → gPath (store @0xfd0 GOT)
3. `GetStaticFieldID(gPath, "mNativePath", "J")` → gNativePathField (0xfd8)
4. `FindClass("androidx/graphics/path/PathIteratorPreApi34Impl")` → 0xb43
5. Reads system property `ro.build.version.sdk` (0xb2e) + `atoi`
   - sdk >= 26 → RegisterNatives(7 natives) table @0x5c48/.data.rel.ro (via rodata @0xcf0 addressing)
   - sdk < 26 → different table @0x5cf0 (legacy layout)
6. `FindClass("androidx/graphics/path/ConicConverter")` (0xab1), RegisterNatives(1): internalConicToQuadratics

**Native method table (JNINativeMethod = name/sig/fnptr, resolved via .rela.dyn R_AARCH64_RELATIVE):**

| Java method | Sig | Native fn @ |
|---|---|---|
| createInternalPathIterator | (Landroid/graphics/Path;IF)J | 0x1888 |
| destroyInternalPathIterator | (J)V | 0x19d4 (→free) |
| internalPathIteratorHasNext | (J)Z | 0x19dc |
| internalPathIteratorNext | (J[FI)I | 0x19ec |
| internalPathIteratorPeek | (J)I | 0x1a80 |
| internalPathIteratorRawSize | (J)I | 0x1ab0 |
| internalPathIteratorSize | (J)I | 0x1ab8 (→0x13c8 big switch) |
| internalConicToQuadratics (ConicConverter) | ... "J" | 0x1ac0 |

**Key implementation details:**
- PathIterator struct (0x238 bytes, malloc @0x192c): offsets 0x0/0x8/0x10 = native handles (x20/x23/x24 copied from mNativePath, GetDirectBufferAddress), 0x18 & 0x1c = sizes, 0x20 = close flag, 0x21 = mode, 0x24 = tolerance (float), 0x28 = segment counter, 0x234 = queue counter
- SDK-version-dependent struct layout (three layouts: sdk>=26, 26..30, <24 switch at 0x1990/0x19b0)
- 0x13c8 = path segment type switch (6 types, jump table @0xaa0): handles SEGMENT types, computes sizes for floats
- 0x1234/0xec0 = recursive conic → quadratic subdivision (level selection based on tolerance; pow/log math at 0xd7c). Approximation level: fits tolerance via 4-sqrt comparisons
- 0x1ac0 internalConicToQuadratics = converts conic to quadratics using NewByteArray/SetByteArrayRegion/GetByteArrayRegion float arrays → outputs float[] of quadratics
- Float math NEON SIMD (ldp/stp paired floats), __stack_chk_fail everywhere (protector enabled)

**Verdict:** 100% stock AndroidX graphics-path. No custom code. (Matches upstream androidx.graphics.path JNI)
