### 21:45 — Admin Access Denied FIX (u is STRING in TPY)
- User (ID 5271912123 = hardcoded admin) got "Access Denied" from /zeron-admin.
- Root cause: TBC/TPY injects `u` as type STR (per docs, TeleBot Studio ref: `u | str`). So `u != 5271912123` (int) is ALWAYS True → everyone denied, admin included. Same latent bug existed in original /zeron-pass.
- Fix: global replace in build script — `u != 5271912123` -> `str(u) != "5271912123"`, `u == 5271912123` -> `str(u) == "5271912123"` (works for both str and int u). Rebuilt: 40 commands, 0 int-u compares, 39 guards, all compile.
- Also fixed menu-injection idempotent strip regex to match new str form.
- LESSON (learned/): TBC `u` = str. Always normalize to str for ID comparisons.
