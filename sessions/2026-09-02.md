## 2026-09-02 — Settings complete rewrite (2nd fix)

### Root causes found:
1. Banner `_inner_w` returned `w-4` = 76 at 80 cols → box 78 chars wide + 2 indent = overflow
2. Sub-menus called `stty sane` then `stty -echo raw` again → broke terminal state
3. Enter key: raw mode sends `\r` (0x0D), not `\n` (0x0A) — old code only checked `\n`
4. `dd bs=1 count=1` unreliable when nested raw mode sessions overlap

### Fix: Complete rewrite
- **No more dynamic-width boxes** in settings — fixed 60-char separator lines
- **Single raw mode session** — `_settings()` enters raw mode once, sub-menus never touch stty
- **Enter detection**: `$'\r'|$'\n'|""` covers all cases
- **`_s_info_page()`** helper: all sub-pages (layout, anim, access, server) use same pattern
- **Theme picker**: descriptions for each theme, live color apply
- **`_apply_theme()`**: only updates cYel/cMag/cCyn/cGrn/cRed/cGry (not cB/cR which are shared)
- **Bash script added to git** in previous commit, now updated
