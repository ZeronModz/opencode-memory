### 13:5X — Compile error in Sketchware (Java 7/8 "effectively final" issue)
- **Problem:** `Cannot refer to the non-final local variable lp/root defined in an enclosing scope` (13 errors).
- **Root cause:** Tomader javac (Sketchware) anonymous inner class e `root`/`lp` access korte pare na — Java 8+ "effectively final" support kore na.

- **Verified:** javac 1.8 + android-34.jar + okhttp3 → clean, 61 class, kono error nai.
- **Lesson (learned):** Sketchware/old javac e anonymous class e local var use korle AGE theke `final` copy banay debe. Source check: Java 8 (1.8) use korechi — source 7 ecompile kora jabe na.
