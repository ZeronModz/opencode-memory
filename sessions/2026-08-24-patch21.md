### 2. Menu: 80 buttons with 2 per row

### 3. Dynamic Toggles: ONE button per feature
Instead of TWO buttons (Torch ON + Torch OFF), now ONE button:
- Click "💡 Torch" → torch toggles → message edits → button text changes
- Click again → toggles back → message edits again

Features with dynamic toggle:
| Button | Callback | Behavior |
|--------|----------|----------|
| 💡 Torch | do:torch | Toggles on/off, button text changes |
| 📶 WiFi | do:wifi | Toggles on/off, button text changes |
| 🔵 Bluetooth | do:bt | Toggles on/off, button text changes |
| 📍 GPS | do:gps | Toggles on/off, button text changes |
| ⌨️ Keylogger | do:klog | Toggles on/off, button text changes |
| 🔔 Notifications | do:notif | Toggles on/off, button text changes |

### Flow:
```
/start → welcome
  ↓ tap "Menu"
  → SAME message edits → 80 buttons (2 per row)
  ↓ tap "💡 Torch"
  → SAME message edits → "Status: ON" + [Torch OFF] button
  ↓ tap "Torch OFF"
  → SAME message edits → "Status: OFF" + [Torch ON] button
  ↓ tap "Commands"
  → SAME message edits → helpText + Back button
  ↓ tap "Back"
  → SAME message edits → welcome
```
