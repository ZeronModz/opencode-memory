## Technical Notes
- All error handlers in tools must return data matching the same shape as success handlers (TypeScript strict mode)
- `ok()` from result.ts infers type from argument, so error cases must include all fields
- Zod v4: `z.record(z.string(), z.unknown())` required (two args)
- Shell script `zeronmcp` handles graceful shutdown via trap INT/TERM
- Server startup: `ensureZeronDirectories()` → `loadConfig()` → `ZeronMcpServer` → `createHttpServer()` → `startHttpServer()`

## 14:50 - ZERON MCP v3.0 UI Overhaul

### Problem
- Emoji characters (🚀📡📋) were double-width in terminal but bash counted as 1
- Box-drawing chars (▀▄▐▌╭╮╰╯) broke alignment on Termux
- Fixed 60-char width didn't adapt to screen size
- No interactive features (pagination, keyboard nav)

### Solution
- Replaced ALL emoji with ASCII-safe symbols (+, x, >, *, #, @, -, |, ~, ...)
- Dynamic width: `W=$(get_width)` reads `tput cols` for all screens
- Proper padding: `printf "%-${name_w}s"` for exact alignment
- Gradient lines use `=` instead of Unicode `━` (which garbled on Termux)
- Added paginated tools view (4 pages, N/P/Q keyboard nav)
- Added typewriter, spinner, progress bar, fade_in animations
- Added fancy_box, gradient_line, center, rep helper functions
- Status view: info panel with proper `|` borders and padding
- Doctor view: clean check/x symbols
