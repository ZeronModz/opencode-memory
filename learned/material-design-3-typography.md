# Material Design 3 — Typography & Shape Reference

## Type Roles (Typescale)
M3 uses a streamlined typescale with 16 roles:

### Display
- Display Large: 57px / 64px line-height / Regular weight
- Display Medium: 45px / 52px / Regular
- Display Small: 36px / 44px / Regular

### Headline
- Headline Large: 32px / 40px / Regular
- Headline Medium: 28px / 36px / Regular
- Headline Small: 24px / 32px / Regular

### Title
- Title Large: 22px / 28px / Medium
- Title Medium: 16px / 24px / Medium
- Title Small: 14px / 20px / Medium

### Body
- Body Large: 16px / 24px / Regular
- Body Medium: 14px / 20px / Regular
- Body Small: 12px / 16px / Regular

### Label
- Label Large: 14px / 20px / Medium
- Label Medium: 12px / 16px / Medium
- Label Small: 11px / 14px / Medium

## Default Font Family
- Roboto (Android)
- SF Pro (iOS - adapted)
- Custom via --md-ref-typeface-brand / --md-ref-typecase-plain

## Shape System
M3 uses corner radii for shape theming:
| Role | Corner Radius |
|------|--------------|
| Extra Small | 2dp |
| Small | 4dp |
| Medium | 6dp |
| Large | 8dp |
| Extra Large | 16dp |
| Full | 9999dp (circle/pill) |

## Shape Examples by Component
- Button: Small (4dp)
- Card: Medium/Large (8dp)
- Chip: Full (pill)
- Dialog: Large (16dp)
- FAB: 16dp
- Input Field: Small (4dp)
- List Item: None / Small
- Menu: Large (16dp)
- Bottom App Bar: None
